### A. 最新の絶対優先順位

**①能力 → ②展開 → ③追切 → ④近走 → ⑤馬場 → ⑥期待値**

1. **能力**：クラス実績・相手関係・走破時計・補正時計・RT6能力M／能平均／着RT等。能力順位をまず市場評価と独立に決定する。
2. **展開**：逃げ先行勢・テン・各コーナー位置・スロー／平均／ハイ・差し届く条件・位置取りコスト・進路リスク。
3. **追切**：最終・1週前・自己比較・過去休み明け・加減速・CW／坂路・調整過程。
4. **近走**：近3〜5走のレベル・脚色・着差・末脚とラップ・上昇／下降・ローテと斤量、休養明けの実績。
5. **馬場**：当日バイアス・芝／ダ別・枠・内外・前後・コース／距離適性・気象・馬体重。
6. **期待値**：上位の競走能力・展開評価を消し込むための根拠にはしない。発走前の実オッズと校正済み**券種別同時成立確率**に基づき、最後に買い目の購入可否・点数・資金・BET／NO BETを決める。印の選定は能力・展開などを主軸とし、EVは補助的な価格監査とする。

- **危険人気馬**：人RT・支持率上位でも能力・ローテ・展開・状態に独立した裏付けが弱い馬。

## 8. 予測確率・組合せ確率の定義

馬数を N とし、相互整合する着順同時分布から必要に応じて以下を導出する。

- `P_win(i) = P(着順_i = 1)`
- `P_top2(i) = P(着順_i ≤ 2)`
- `P_top3(i) = P(着順_i ≤ 3)`
- `P_quinella(i,j) = P({着順_i, 着順_j} = {1,2})` ：馬連
- `P_wide(i,j) = P(着順_i ≤ 3 かつ 着順_j ≤ 3)` ：ワイド
- `P_trio(i,j,k) = P({着順_i,着順_j,着順_k} = {1,2,3})` ：三連複
- `P_trifecta(i,j,k) = P(着順_i=1, 着順_j=2, 着順_k=3)` ：三連単

**重要**：各馬の勝率・複勝率の積をそのまま組み合わせ成立確率にしてはならない。着順は排他的であり、脚質・展開・相手関係による相関がある。シミュレーションもしくは一貫したランキング同時モデルから推定する。

- JRAの100円当たり払戻額を `D_yen`、予測的中確率を `p` とすると `期待払戻(100円券)=p×D_yen`、`期待利益=p×D_yen−100円`。通常のオッズ倍率 `o` を使う場合は `EV比率=p×o−1`。
- **予測時には市場で購入可能な当該券種・当該組み合わせのオッズが必要**。歴史的確定払戻のみで事前予測の期待値を既知だったかのように扱わない。
- 返還・同着・特払・控除や発売条件の例外はJRA規定に基づき精算する。
- 検証にはcalibration curve、Brier Score、log-loss、top-k捕捉、券種別ROI、ドローダウン、点数、推奨率、予想確率の校正を使用する。

## 9. PHASE20・買い目構築の強制ルール【最重要・2026-10-11】

1. **馬の評価と印は能力を最重要、馬券の採否と組合せは保守的EVを最重要**とする。◎が含まれていてもEVが負なら買わず、◎不在でも独立した能力根拠と適切な確率校正がある正EVの○▲☆△間組合せは採用候補にできる。馬券候補は◎固定ではなく、○▲☆△・△同士も独立して評価する。
2. 馬連とワイドの購入点数は**別々**に最大5点（合算5点ではない）。両方0点も許可、上限5点に自動的に埋めない。波乱度低→0〜2点、中→2〜4点、高→4〜5点は**参考目安**であり機械的に決めない。
3. 三連複・三連単はレースの性質に応じて採用し、無理な全流し・固定フォーメーションを禁止する。単勝・複勝は推奨しない。
4. 同じ2頭の**馬連とワイド併用は、券種ごとの成立確率・配当・リスク目的が妥当なら許容**。「同じペアがある」という理由のみで片方を削除してはいけない。
5. 券種横断で**同一馬軸への過度集中**、一シナリオ依存、同じ組合せ群の買い増し、選定済み☆△の活用不足を監査。ただし**分散そのものを目的化しない**。
6. 本線を削除する際は、オッズ、成立確率、追加的価値、資金制約、反証結果の**積極的な根拠**を必須とする。機械的な分散調整で本線を失うことは禁止。
7. 馬連は1・2着ペア、ワイドは3着内ペア、三連複は3頭セット、三連単は着順の再現を狙う。券種間で「なぜその点数か／買い目か」を説明する。
8. 必ず購入なし（NO BET）も比較する。価格が未取得で期待値が判断できない場合、無理に「プラス期待値」と表現しない。
9. 予想印の的中捕捉率と、**実際に買った買い目の的中・収支**を分離し、両方報告する。
10. 初版→改訂版→**発走前最終確定版**の買い目差分、オッズ時点、削除・追加理由を保存。回収実績は最終版のみ。削除した的中買い目は「改訂の失敗」として別監査する。
11. 実際の資金配分が未指定なら「100円均等」の仮定を明示し、実購入と混同しない。
12. 市場価格、馬券点数、最終印7頭、当日追切、馬体重、確定結果などについて欠落があれば監査表に `UNVERIFIED` を明示する。

### 組合せ選定の監査観点

- ◎採用率（全買い目中、軸馬を含む割合）、上位3頭のみの券数、穴馬を含む券数、同ペア重複数。
- ペース分岐（スロー・平均・ハイ）、当日バイアス逆転、人気馬失速／穴馬同時台頭の条件付き回収性。
- 各候補の `追加期待利益` と `ポートフォリオ全体への追加価値` を、独立した券種確率・購入時価格・相関から判断。
- **重複＝即削除ではない**。**穴馬＝即購入ではない**。能力・予測・市場・価格の裏付けが必要。

### 3. PHASE18：券種別同時成立確率とEVを必ず計算【強制】

4. 計算結果には**証拠区分**を必須表示する：`VALIDATED/AS-OF`（前向き妥当性確認済み）／`EXPERIMENTAL EV`（未較正・研究用）／`CONDITIONAL EV`（確率またはオッズを仮置きした条件付き演算）／`EV算定保留`（少なくとも一方が不明）。`CONFIRMED`な価格取得だけで`VALIDATED`な勝率・プラスEVになることはない。

6. 資料にペアの`p`だけがあって券種価格がない場合は `必要最低オッズ=1/p` を明記し、**「現在オッズを入手するまで購入保留」**とする。`p`も欠ける場合は閾値すら捏造しない。馬券を無理に出す代わりに不足入力を明確にする。

### B. EV算出・比較・優先選択

1. 候補券種は馬連、ワイド、三連複、三連単。単勝・複勝は推奨しない。**可能な候補を広く列挙し、採用・見送りの両方を比較**する。評価対象の組合せ確率は同一の着順同時分布から推定し、独立勝率や3着内率の単純積は禁止。
2. 各候補について、`p=券種固有成立確率`、`o=当該時点に購入可能な券種別オッズ`、`EV(%)=100×(p×o−1)`、`EV(円/100円)=100×(p×o−1)`、`損益分岐倍率=1/p`を計算。ワイド等のオッズ範囲は**下限を優先したEV**を用いる。オッズ欠損はEV未算定、確率欠損は判定保留。

4. **高配当・低的中率の過大評価を防止**：数回のシミュレーション成立、薄い芝ダート転換仮定、未較正のPlackett–Luce、恣意的な市場確率と試験モデルのブレンド比率などだけで高EVを作り、優良購入券として断定することは禁止。小標本の極端な正EVは原則保留し、感度分析と再現性を必須にする。
5. 選択順は**(a)時点・モデル妥当性ゲート → (b)保守的EV（最優先） → (c)追加期待利益／予想ROI → (d)展開別の頑健性・損失集中／相関 → (e)投資額・点数上限**。能力は(a)の確率推定を支える重要情報であり、(b)を無視する買い目採用理由にはならない。

7. **同じ組合せの馬連・ワイド併用、○▲☆△間の馬券、◎不在の買い目を機械的に除外しない**。ただし無根拠の「分散」を目的に正EVの本線を削除・負EVのヘッジを追加しない。

### C. 券種・資金・点数最適化

1. 馬連は**0〜5点**、ワイドは**0〜5点**、各々独立上限。三連複・三連単はEV・リスク・予算に応じて必要時のみ。最大点数へ自動的に埋めない。最適解が全券種0点ならNO BET。
2. 予算指定時は**保守的期待利益が最大となる資金配分**を、購入最小単位・一日/一レース損失上限・ポートフォリオの集中リスクの範囲で探索する。高EV率のみを理由に全額集中させない。予算未指定なら**各100円等の仮定**で参考比較し、実購入指示と混同しない。
3. `総期待利益 = Σ(各券の100円あたり期待利益 × 購入額/100)`、`予想ROI = (総投資額+総期待利益)/総投資額`。相関があっても期待利益の和は線形に計算できる一方、連続不的中・分散・損失確率は同時分布で別途評価する。総投資0円（NO BET）ならROIは**計算対象外**とする。
4. **固定券種・固定フォーメーション・馬連/ワイド機械的セット購入を禁止**。印を7頭にしたからといって全頭を買う必要はない。
5. 市場比較は参考情報。**市場暗黙確率だけを市場価格で割り戻したEV**は、それだけでは優位性の検出にならない。独立の的中確率推定と前向き校正を確認すること。

### D. 出力・監査・公開版の必須項目

1. **予想**：能力・適性重視の最終印（最大7頭）、危険人気馬、注目穴馬、最重要馬。
2. **買い目EVランキング**：券種、組合せ、`p`、オッズ（取得時刻）、損益分岐、基準EV%、保守的EV%、100円期待利益、証拠区分、採用・見送り理由を比較。数値のない欄には`未取得/未計算/未検証`を正確に明示する。
